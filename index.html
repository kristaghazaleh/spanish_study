How this page is meant to work

This is not trying to be a textbook. It is a working reference: search what you need, open the category, read the human explanation, then copy the example sentence pattern into your own Spanish.

For Costa Rican Spanish, the safest path is to get comfortable with usted and recognize vos. You will still see tú because music, Duolingo, shows, and other Latin American speakers use it, but this site does not treat Spain-style vosotros as a main target.

Tense map

Use this as the mental order. Get the first row strong, then add the second row, then treat subjunctive as its own project.

Present

What is true, habitual, or happening now. Hablo, como, vivo.

Near future

The practical future: voy a estudiar. Learn this early because people use it constantly.

Preterite

Completed past action: ayer estudié, fui, terminé.

Imperfect

Background or repeated past: era, tenía, estudiaba.

Future

Prediction or formal future: hablaré, comerá, viviremos.

Conditional

Would / polite softening: quería can be imperfect, but querría is would want.

Present perfect

Have done: he estudiado, hemos visto.

Subjunctive

After desire, doubt, need, emotion, uncertainty: quiero que vengas.

Verb tense master tables

This section separates the six main one-word conjugation sets from helper-verb constructions. Use it as a quick map while reading real Spanish.

Back to tense map

Big rule: simple tenses change the verb itself: estudio, estudié, estudiaba, estudiaré, estudiaría, estudie. Helper constructions use another verb: estoy estudiando, he estudiado, voy a estudiar.

Present Preterite Imperfect Future Conditional Present subjunctive Irregulars Helper constructions
1. Present tense / presente — regular endings

Use: facts, habits, general present, and sometimes “am/is/are doing” depending on context.

Examples: Estudio español. = I study Spanish / I am studying Spanish. Como pasta. = I eat pasta / I am eating pasta.

Subject-AR: estudiar-ER: comer-IR: vivir
yo-o → estudio-o → como-o → vivo
tú-as → estudias-es → comes-es → vives
él / ella / usted-a → estudia-e → come-e → vive
nosotros/as-amos → estudiamos-emos → comemos-imos → vivimos
ellos / ellas / ustedes-an → estudian-en → comen-en → viven
2. Preterite / pretérito — completed past action

Use: completed past events: what happened, what you did, what finished.

Examples: Ayer estudié. = Yesterday I studied. Comí pasta. = I ate pasta.

Subject-AR: estudiar-ER: comer-IR: vivir
yo-é → estudié-í → comí-í → viví
tú-aste → estudiaste-iste → comiste-iste → viviste
él / ella / usted-ó → estudió-ió → comió-ió → vivió
nosotros/as-amos → estudiamos-imos → comimos-imos → vivimos
ellos / ellas / ustedes-aron → estudiaron-ieron → comieron-ieron → vivieron

Watch: regular -AR nosotros looks the same in present and preterite: estudiamos = we study / we studied. Context decides.

3. Imperfect / imperfecto — used to, was doing, background past

Use: repeated past habits, background descriptions, ongoing past actions, age/time/weather in the past.

Examples: Estudiaba mucho. = I used to study a lot / I was studying a lot. Vivía en California. = I used to live in California / I was living in California.

Subject-AR: estudiar-ER: comer-IR: vivir
yo-aba → estudiaba-ía → comía-ía → vivía
tú-abas → estudiabas-ías → comías-ías → vivías
él / ella / usted-aba → estudiaba-ía → comía-ía → vivía
nosotros/as-ábamos → estudiábamos-íamos → comíamos-íamos → vivíamos
ellos / ellas / ustedes-aban → estudiaban-ían → comían-ían → vivían
4. Future / futuro — will do

Use: future events, predictions, promises, and sometimes formal-sounding future statements.

Build: keep the whole infinitive, then add the ending.

SubjectEndingestudiarcomervivir
yo-éestudiarécomeréviviré
tú-ásestudiaráscomerásvivirás
él / ella / usted-áestudiarácomerávivirá
nosotros/as-emosestudiaremoscomeremosviviremos
ellos / ellas / ustedes-ánestudiaráncomeránvivirán

Everyday shortcut: people often use voy a + infinitive: Voy a estudiar. = I am going to study.

5. Conditional / condicional — would do

Use: would do, polite softening, hypotheticals, wishes.

Build: keep the whole infinitive, then add the ending.

SubjectEndingestudiarcomervivir
yo-íaestudiaríacomeríaviviría
tú-íasestudiaríascomeríasvivirías
él / ella / usted-íaestudiaríacomeríaviviría
nosotros/as-íamosestudiaríamoscomeríamosviviríamos
ellos / ellas / ustedes-íanestudiaríancomeríanvivirían

Useful phrase: Me gustaría verte. = I would like to see you. Me encantaría verte. = I would love to see you.

6. Present subjunctive / presente de subjuntivo — wishes, doubt, emotion, uncertainty

Use: after triggers like quiero que, espero que, necesito que, me alegra que, tengo miedo de que, and some future/uncertain cuando clauses.

Build: take the present yo form, drop -o, then use the opposite vowel endings.

Subject-AR: estudiar-ER: comer-IR: vivir
yo-e → estudie-a → coma-a → viva
tú-es → estudies-as → comas-as → vivas
él / ella / usted-e → estudie-a → coma-a → viva
nosotros/as-emos → estudiemos-amos → comamos-amos → vivamos
ellos / ellas / ustedes-en → estudien-an → coman-an → vivan

Examples: Quiero que estudies. = I want you to study. Espero que llegues pronto. = I hope you arrive soon. Cuando llegue, te llamo. = When I arrive, I’ll call you.
