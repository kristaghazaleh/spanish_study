How this page is meant to work

This is not trying to be a textbook. It is a working reference: search what you need, open the category, read the human explanation, then copy the example sentence pattern into your own Spanish.

For Costa Rican Spanish, the safest path is to get comfortable with usted and recognize vos. You will still see tú because music, Duolingo, shows, and other Latin American speakers use it, but this site does not treat Spain-style vosotros as a main target.

Tense map

Use this as the mental order. Get the first row strong, then add the second row, then treat subjunctive as its own project.

Present

What is true, habitual, or happening now. Hablo, como, vivo.

Near future

The practical future: voy a estudiar. Learn this early because people use it constantly.

Preterite

Completed past action: ayer estudié, fui, terminé.

Imperfect

Background or repeated past: era, tenía, estudiaba.

Future

Prediction or formal future: hablaré, comerá, viviremos.

Conditional

Would / polite softening: quería can be imperfect, but querría is would want.

Present perfect

Have done: he estudiado, hemos visto.

Subjunctive

After desire, doubt, need, emotion, uncertainty: quiero que vengas.
